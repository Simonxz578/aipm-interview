# C端优缺点
优势：
长期真实用户观察、教育用户理解、公开0→1、AI质量/评测、国际化。
短板：
缺少亿级C端组织里的增长与大流量实验。
补齐：
用数据实验思维作答，并说明希望在核心业务补规模化经验。

# 广告素材AI
人群/商品/场景分层
→ 素材原子
→ 受控生成
→ 品牌/合规
→ 预测过滤
→ 小流量探索
→ CTR/CVR/ROI
→ creative fatigue
→ 回流高质量特征。

产品负责：
目标、口径、用户、素材schema、实验、合规、业务指标、体验。

算法负责：
模型、特征、训练、推理优化。

共同：
Eval与上线。

# 未来Agent
从chat-first向goal/workspace-first：
用户说目标，系统结合历史状态、文件、工具和权限持续推进。
界面从聊天记录变成计划、任务状态、产物和审批。
自主权越大，权限、确认、撤销、审计越重要。
